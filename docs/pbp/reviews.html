Errors + official scoring pending

A focused feed for all games on the selected date. It shows current official field-error calls, error-involving scoring changes this page actually observed, and exact primary official-scorer-pending rulings.

How to read the score. For an official error, the “Hit outcome score” is the model's estimated share for a final hit label from the ball's recorded data. It is not the chance that an existing error will be changed to a hit: the current model was not trained on error-to-hit transitions. For an active official scoring-pending ruling, the model shows its most likely outcome group and detailed class. All estimates are experimental; they are not official scorer rulings, and the model validation audit is unresolved.
What this feed includes and excludes
  • Current error: the play's official result.eventType is field_error.
  • Official scoring pending: only the exact os_ruling_pending_primary event-type code is scored. The os_ruling_pending_prior code concerns a prior base-running event, so it is excluded from batter-outcome predictions.
  • Error reclassification: shown only when this browser observed an error on one poll and a different official classification on a later poll. A final-only feed cannot recover an unobserved initial call.
  • Not shown: manager challenges, umpire reviews, ABS challenges, boundary calls, and ordinary non-error plays.
  • No score: if the model or required Statcast measurements are missing or invalid, the play stays visible without an invented estimate.

Data: the public MLB StatsAPI and its official event-type registry. Model estimates use the committed ErrorsLive model; the current implementation does not estimate scorer-change odds. Not affiliated with MLB or MLB Advanced Media.
