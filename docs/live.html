Live board — the model on the official feed, ball by ball

Rows are produced by tools/fetch_live.py from statsapi.mlb.com and committed as data/live_now.json by the CI job (or run locally: the command is at the bottom of this page). Every game is re-checked against the league's own linescore endpoint before its rows are shown.

What the SCORE/100 column is. 100 × P(the official scorer rules this batted ball an error). Out-of-fold, the model never nominates “error” as its most likely ruling, so treat the column as a ranking of where to look — it is not a verdict, and the official scorer's call in the feed is the source of record.

Run it yourself

python3 tools/fetch_live.py                        # today's slate (US Eastern game date)
python3 tools/fetch_live.py --date 2026-09-28      # a specific date
python3 tools/fetch_live.py --pk 823441            # one game, live, mid-inning
python3 tools/fetch_live.py --out docs/data/live_now.json --csv /tmp/live.csv

Needs outbound HTTPS to statsapi.mlb.com. Where that is blocked (this build sandbox), the committed snapshot above is what the CI runner fetched — with its own timestamp, so you always know how old the board is.

Can this page poll the feed itself?

The button asks statsapi.mlb.com from your browser. If the league's endpoint answers with permissive CORS headers, the result is shown — that is the honest test, run in front of you rather than asserted in advance.
