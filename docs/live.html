Live board — the model on a real game, ball by ball

This is the “give me a live feed” half of the project. Every row below was produced by tools/live_score.py from a verbatim capture of the official MLB live feed for game 823441 (MIA @ NYM, 2026-07-18 — the error-richest game in the archive, 4 team errors and 3 overturned challenges). The raw capture, its fetch URL and its official box score are recorded in data/source/feed_823441.json; the output is re-generated by the pipeline, not typed by hand.

Read this first. The SCORE/100 column is P(error)×100. Over the 1,258 labelled batted balls in the fitting set it only ever ranges 0.01 – 6.48, and the model never picks “error” as its most likely ruling. So the column is a ranking, not a verdict: what it is genuinely good at is telling you which of 46 batted balls in a game sits at the top of the error-likelihood distribution. Use it to decide where to look, never to decide a call.

What each column means

SCORE/100 & top pick

SCORE/100 is 100 × P(ruled error) from the binary model — the same number the calculator shows. Top pick is the most probable of the four macro classes from the 4-class model, with its probability. ✓ in the last column marks the plays where the model's top pick matched the official ruling.

Runners / RBI columns

On is the base state before the ball was hit, read from the feed's runner-movement data. When a runner is on 2nd/3rd and a run scores, the RBI if… columns spell out what the batter's RBI would be under each candidate ruling, straight from the MLB glossary rules on the rules page.

Run it yourself, on today's games

The tool needs outbound HTTPS to statsapi.mlb.com. Where that is blocked, everything still works offline from a saved feed.

python3 tools/live_score.py --today              # every game on today's MLB slate
python3 tools/live_score.py --pk 823441         # one game
python3 tools/live_score.py --feed data/source/feed_823441.json   # offline, no network
python3 tools/live_score.py --backtest --csv /tmp/backtest.csv    # all 24 archived games
Honest limitation: the page above is a replay of the tool, not a live poll. This sandbox has no direct outbound HTTPS to statsapi.mlb.com, so a genuinely live fetch could not be demonstrated from here; the capture above was fetched through the session's HTTPS relay and stored unmodified. Run --today from an unrestricted machine for a real live board.
