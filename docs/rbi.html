RBI stakes, measured — does an error cost the batter an RBI?

The brief asks a question with a checkable answer: if a play is ruled an error, does the batter lose the RBI he would have had on a hit or a fielder's choice? That is a question about the official statistic, so it can be measured rather than modelled. Every batted ball in the collected window carries the feed's own result.rbi together with the base/out state the scorer already knew.
