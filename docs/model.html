The model, and the evidence for it

Everything on this page is recomputed from docs/data/model.json, fitted by tools/train_model.py from the committed batted-ball CSV. The model estimates whether a play's final captured feed label is an error; it does not estimate the chance that an initial call will later be changed. The audit suite re-derives the metrics on every push.

Scope: this is a late-season 2026, single-season model. The reported cross-validation holds out games from the same collected window; it is not a test on future seasons, unseen scorers or a complete season.

How it is validated

Grouped cross-validation (the headline)

Folds are split by game, not by play. Each fold's StandardScaler is fitted on that fold's training games only. A stratified random-fold score is shown as a comparator; it is not assumed to be an upper or lower bound. The signed random-minus-grouped difference is published (–).

Uncertainty

Intervals come from a 1,000-draw group bootstrap (whole games resampled with replacement), so the interval reflects how much the estimate would move with a different set of games — the honest source of variance here, not the number of plays.

High-score review queue — grouped out-of-fold results

If the score is used to prioritize a limited number of plays, this table shows the observed error precision and recall among the highest-scored fraction of held-out games. The baseline precision is the model window's error rate. These are retrospective same-window results, not a promise about future seasons.

Calibration — do predicted probabilities track observed rates?

The raw calibration table is grouped out-of-fold. A nested GroupKFold isotonic Brier score is also reported: inner-fold predictions fit each calibrator, and the outer held-out games evaluate it. Does nonlinearity help?

A gradient-boosted tree model is trained on the same grouped folds purely as a check. If it cannot beat the logistic model, the extra machinery is not buying anything and the simpler, interpretable, calibratable model stays — –

The published coefficients

Standardized coefficients (per standard deviation), with 95% group-bootstrap intervals. The intercept is the log-odds for an average batted ball.

Correlations and mutual information

A coefficient can be large because a feature is rare or because it is genuinely informative. These are the raw, model-free associations with the error label: point-biserial r for 0/1 features, Spearman rho for continuous ones, plus mutual information in bits.
