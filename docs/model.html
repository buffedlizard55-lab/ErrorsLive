How it is validated

Grouped cross-validation (the headline)

Folds are split by game, not by play. Plays inside one game share a park, a pitching mix, a weather night and a scorer; random folds let the model memorise those and inflate the score. The grouped number is what this site quotes, and the random-fold number is shown beside it as the optimistic bound, with the gap published (–).

Uncertainty

Intervals come from a 1,000-draw group bootstrap (whole games resampled with replacement), so the interval reflects how much the estimate would move with a different set of games — the honest source of variance here, not the number of plays.

Calibration — is the number trustworthy where it is large?

If the observed rate in a bin is far from the predicted mean, the number is miscalibrated and must not be read as a probability. Isotonic re-calibration is fitted out-of-fold and its Brier score published next to the raw one.

Does nonlinearity help?

A gradient-boosted tree model is trained on the same grouped folds purely as a check. If it cannot beat the logistic model, the extra machinery is not buying anything and the simpler, interpretable, calibratable model stays — –

The model-free empirical surface below (error rate per trajectory × exit-velocity band, with Wilson intervals) is the check that does not depend on any model being right.

The published coefficients

Standardized coefficients (per standard deviation), with 95% group-bootstrap intervals. The intercept is the log-odds for an average batted ball.

Correlations and mutual information

A coefficient can be large because a feature is rare or because it is genuinely informative. These are the raw, model-free associations with the error label: point-biserial r for 0/1 features, Spearman rho for continuous ones, plus mutual information in bits.
