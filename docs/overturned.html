MLB overturned replay calls, 2014–2018

Source: NY Daily News – mlb-overturned-calls (the repo referenced in the brief as “MLB-overturned-calls”), all manager/instant-replay challenges tracked 2014–2018 with video links. Two different overturn mechanisms exist in baseball — this page covers umpire-call reviews; the scorer's hit/error revisions are the model pages. Both change runs and both belong in one honest UI, clearly labeled.

Video-link status (verified 2026-09-29): the archive's t.co/bit.ly/atmlb.com short links point at MLB.com video pages from 2014–2018; MLB later migrated its video platform and many links now 404 or redirect (spot checks returned Cloudflare 5xx). Every row below offers the original source link and a one-click MLB Film Room search for the same play (player + game) — currently the most reliable way to watch the play inside your browser. No videos are re-hosted; all links are official-source only.

Plays where a run was removed or kept off the board heuristic

Flag rule (from tools/build_nydn.py, printed verbatim): result == Overturned AND (initial_call mentions score/home/plate/run OR play-type mentions Timing / HP / Home / Plate / Collisions). It is a heuristic — MLB's official record of whether the run was erased is the box score; this column is an index aid, not gospel.

The amber ⚾ run chip is a heuristic match check on the call description — it marks plays that plausibly decided a run at the plate; the authoritative answer is the recompiled box score (roadmap item #3).
