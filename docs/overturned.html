MLB overturned replay calls, 2014–2018

Every manager / instant-replay challenge the New York Daily News tracked between 2014 and 2018, normalised from their public archive into a single searchable table with a watch link on every row. Two different overturn mechanisms exist in baseball and this page covers only one of them: ① umpire replay challenges (safe/out, fair/foul, homer reviews — this page) versus ② official-scorer hit/error revisions (the model pages). Both move runs; keeping them in separate, clearly-labelled ledgers is the honest way to present them.

Source-of-record note, verified 2026-09-29. The URL in the original brief, github.com/buffedlizard55-lab/MLB-overturned-calls, returns HTTP 404 — that repository does not exist under that name. The archive this page actually uses is the public, verifiable original: github.com/nydailynews/mlb-overturned-calls ↗ (9 published CSVs, vendored byte-for-byte into data/source/nydn/ so the build is reproducible offline). If the buffedlizard55-lab repo is later created, it should be checked against this one rather than assumed to be the same data.

What “normalised” means here — the full policy, printed. The archive's date column is messy in four different ways, all of them verified by reading the vendored source files line by line. Every repair below removes a formatting artefact and no data, the original string is always kept in the date_raw column, and each repair is counted in data/nydn_quality.json:
  • 2,109 rows zero-padded — 2014-4-1 → 2014-04-01. The same day, written without leading zeros.
  • 234 rows written in prose — Sep. 1 → 2014-09-01. The year is taken from the file the row was published in, never guessed from the row; a prose date in an off-season month is left verbatim because the year would be ambiguous.
  • 279 rows carried a stray quote — 2018-05-29" → 2018-05-29.
  • 271 rows were being swallowed by the CSV reader — 206 lines in the 2014 file open with a stray quote and 65 postseason lines open a quoted cell they never close. A plain reader merged each of those records into the previous one, silently losing them. The quote is removed before parsing; no other character is touched.
What is deliberately not repaired: five rows the archive dated 2014-04-31. April 31st does not exist. Whether the archive meant March 31st or April 30th cannot be determined from the source, so those rows keep the impossible date verbatim and are flagged rather than being “fixed” into a game that never happened. A sixth irregularity is a junk line of commas at 2016-mlb-replays.csv:1501 — a fragment of a re-inserted header, not a record, so it is dropped and the drop is logged.

Watch it in your browser

Every row carries two links. source ↗ is the original link from the archive — these are bit.ly/t.co/atmlb.com short links to MLB.com video pages from 2014–2018, and MLB has since migrated its video platform, so many now 404 or bounce. film room ↗ opens MLB's own Film Room search for the same player and game, which is the most reliable way to actually watch the play today. Plays where a run was removed or kept off the board heuristic

Flag rule, printed verbatim from tools/build_nydn.py: result == Overturned AND (initial_call matches score/home/plate/run OR play_type or initial_call matches Timing / HP / Home / Plate / Collisions). This is a heuristic, not a measurement. It is an index aid to get you to the right rows; the authoritative record of whether a run was erased is the recompiled box score, which this project does not yet have (see roadmap item 3).

The amber ⚾ run chip is a heuristic match check on the call description — it marks plays that plausibly decided a run at the plate. It is not a box-score diff.
