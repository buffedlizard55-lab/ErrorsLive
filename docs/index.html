How will the scorer rule it?

A batted ball leaves the bat with a measurable exit velocity, launch angle, distance, trajectory and contact hardness — and a base/out state the scorer already knows. Between contact and the official ruling there is a judgment call about “ordinary effort” (MLB's official error definition). This page runs the model on those inputs and returns the numbers a live pipeline can read straight off the MLB Stats API feed.

Why a hit-vs-error ruling matters — the RBI stakes

A runner on 2nd or 3rd whose run scores because of a misplay produces no RBI if the play is ruled an error — but the batter keeps the RBI if it's a hit, and a run-scoring fielder's choice can still earn one. MLB's official glossary is explicit: batters do not receive RBIs for runs that would not have scored without the help of an error, and no RBI when the run scores as a result of an error or a ground into double play. Flip one scorer's judgment on a borderline grounder and you change a batting line, a fantasy scoreboard, an arbitration number. Full rule walkthrough with verbatim citations →
