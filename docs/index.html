Important: the “Hit outcome score” is not rescore odds. The committed model estimates an outcome class from batted-ball data. For an official error, the displayed hit score is the model's estimate for a final hit label; it is not a trained probability that an already-issued error call will change to a hit. The current model has no validated error-to-hit transition forecast. The scores are experimental; see model details and limitations.
Scope for this first version
  • “Official scoring pending” is included only when the MLB StatsAPI reports the exact os_ruling_pending_primary plate-appearance code. The separate prior base-running marker is not scored as a batter ruling.
  • Error changes appear only when the browser observed an earlier and later official feed classification. A final-only payload cannot reconstruct an unseen initial call.
  • Manager challenges, umpire reviews, ABS challenges, boundary calls and ordinary batted balls are kept out of the focused feed.

Data are read from the public MLB StatsAPI. This is an unofficial fan project, not affiliated with MLB.
