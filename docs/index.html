How will the scorer rule it?

A batted ball leaves the bat with a measurable exit velocity, launch angle, distance, trajectory and contact hardness — and a base/out state the scorer already knows. Between contact and the official ruling there is a judgment call about “ordinary effort” (MLB's official error definition). The model uses those permitted inputs to estimate whether the latest captured official feed label is an error. It does not predict whether an initial call will later be reclassified. The live board fetches the public MLB Stats API feed directly when browser access is available, and the alert console watches it for you — it polls, diffs each capture against the last, and raises an alert when a ruling appears, changes, or moves an RBI, with the rule text and the video link attached.

Why a hit-vs-error ruling matters — the RBI stakes

A run with a runner on 2nd or 3rd does not settle the batter's RBI by itself. Rule 9.04 of the 2026 Official Baseball Rules decides it, and its text is quoted verbatim on Rules & RBI: an error-dependent run earns no RBI under 9.04(a)(1) — unless 9.04(a)(3) applies, which credits one “when, before two are out, an error is made on a play on which a runner from third base ordinarily would score”. That “ordinarily would score” is the scorer's counterfactual and is not in the feed, so the site shows conditional notes, never automatic answers. RBI stakes, measured tabulates what the feed actually credited for each final call and base/out state.
