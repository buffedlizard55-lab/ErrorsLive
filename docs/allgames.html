⚾ Live scoring feed · all games

One feed for the whole slate. Every completed batted ball arrives with the committed model's distribution over the outcomes the official scorer can charge — single / double / triple / home run / error / fielder's choice / field out / force out / double play / sacrifice fly / sacrifice bunt — and the plays the feed marks as an official scorer ruling pending are scored the same way, so you can see how the model weights a hit versus an error versus a fielder's choice before the official call lands. Feed rows show exactly what the official payload said; model numbers are estimates and never a ruling.

Read this before trusting a number. The model estimates the final captured feed label from batted-ball physics and the pre-pitch base/out state. It does not predict whether a scorer will change a ruling, it never nominates “error” as its top multiclass call, and its grouped held-out error recall is zero at the arg-max — the score ranks plays for review, it does not settle them. ⚖️ Pending is only the exact registry marker (os_ruling_pending_primary / os_ruling_pending_prior) or the exact description “Official Scorer Ruling Pending”; a missing result.eventType without that marker is shown as no event type in this capture. ✏️ Changes are differences this browser observed between two reads of the same play. Row times are when this browser first saw the play — the official payload has no per-play timestamp — and are labelled as such.

Where each kind of row comes from. Batted balls — liveData.plays.allPlays[] in the official live feed; the distribution is docs/data/model.json's 11-class head, whose grouped held-out top-1 accuracy is printed on Live board and documented on Model & validation. Pending — the API's own event-type registry (/api/v1/eventTypes ↗), detected by the shared ScoringFeed module exactly as on Live alerts. Changes — the browser observation ledger (errorslive.scoring-feed.v1) diffing consecutive reads; the feed carries no change marker, so an initial call is only known if it was observed before it changed. Reviews — reviewDetails in the official payload, labelled from the league's own status registry ↗ when it can be fetched (otherwise the raw code is shown). Official feed links on every row point at statsapi.mlb.com.
